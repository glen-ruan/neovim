# 快捷键

Leader 键为 `Space`。本文中的“空格”均表示 Leader。

## Neovim 基础移动

| 操作 | 快捷键 |
|---|---|
| 左、下、上、右 | `h`、`j`、`k`、`l` |
| 当前屏幕顶部、中部、底部 | `H`、`M`、`L` |
| 文件首行、末行 | `gg`、`G` |
| 半页向下、向上 | `Ctrl-d`、`Ctrl-u` |
| 跳到指定行 | `<行号>G` |
| 进入命令行 | `:` |
| 清除搜索高亮 | `Esc` |

## 文件、Buffer 与窗口

| 操作 | 快捷键 |
|---|---|
| 保存 | `空格 w` |
| 退出当前窗口 | `空格 q` |
| 删除当前 Buffer | `空格 b d` |
| 下一个、上一个 Buffer | `空格 PageDown`、`空格 PageUp` |
| 跳到第 1–9 个 Buffer | `空格 1` 至 `空格 9` |
| 打开或隐藏 Buffer 栏 | `空格 t b` |
| 打开文件树 | `空格 e` |
| 垂直、水平分屏（仅普通编辑窗口） | `空格 s v`、`空格 s h` |
| 平均分配窗口 | `空格 s e` |
| 关闭当前分屏 | `空格 s x` |
| 切换左、下、上、右窗口 | `空格` + 对应方向键 |

创建分屏快捷键只在普通编辑 Buffer 中生效。在文件树、终端、帮助、health 和快速修复窗口中误按时不会创建分屏；插件自己的预览和跳转窗口不受影响。

## 查找与导航

| 操作 | 快捷键 |
|---|---|
| 查找文件 | `空格 f f` |
| 全文搜索 | `空格 f g` |
| Buffer 列表 | `空格 f b` |
| 最近文件 | `空格 f r` |
| 项目列表 | `空格 f p` |
| 命令历史 | `空格 :` |
| 搜索历史 | `空格 /` |
| 通知历史 | `空格 n h` |
| 代码大纲 | `空格 o` |

## 选择与缩进

| 操作 | 快捷键 |
|---|---|
| 选中当前词 | `空格 v c` |
| 选中当前行 | `空格 v l` |
| 选中到配对括号 | `空格 v v` |
| Visual 模式增加、减少缩进 | `Tab`、`Shift-Tab` |

## LSP 与诊断

以下快捷键在对应语言服务器附加后可用。

| 操作 | 快捷键 |
|---|---|
| 跳转定义、声明 | `g d`、`g D` |
| 查找引用 | `g r r` |
| 跳转实现、类型定义 | `g I`、`g y` |
| 查看符号说明 | `K` |
| 插入模式查看函数签名 | `Ctrl-s` |
| 代码操作 | `空格 c a` |
| 重命名符号 | `空格 r n` |
| 格式化当前文件 | `空格 c f` |
| 当前文件、工作区符号 | `空格 s s`、`空格 s S` |
| 诊断选择器 | `空格 s d` |
| Trouble 诊断窗口 | `空格 x x` |

运行 `:LspAvailability` 可查看每个语言服务器是否可用。

`K` 和插入模式 `Ctrl-s` 打开的提示都是不可聚焦的临时浮窗；移动光标后自动关闭，不使用 `q` 退出。

## Git

|---|---|
| Git 状态 | `空格 g s` |
| 当前改动列表 | `空格 g d` |
| 打开 Diffview | `空格 g v` |
| 关闭 Diffview | `空格 g q` |
| 当前文件历史 | `空格 g f` |
| 仓库文件历史 | `空格 g l` |

## 调试

以下快捷键和 `:DebugPython` 在首次打开 Python Buffer、加载 DAP 后可用。

| 操作 | 快捷键 |
|---|---|
| 启动或继续 | `F5` |
| 停止调试 | `F6` |
| 切换断点 | `F9` |
| 单步跳过、进入、跳出 | `F10`、`F11`、`Shift-F11` |
| 打开或关闭调试界面 | `空格 d u` |
| 查看表达式 | `空格 d e` |
| 条件断点 | `空格 d b` |

Python 调试可使用 `:DebugPython [脚本路径]`。

## 终端与写作

| 操作 | 快捷键或命令 |
|---|---|
| 打开或隐藏浮动终端 | `空格 f t` |
| 终端模式返回普通模式 | 连按两次 `Esc` |
| Quarto 预览、关闭预览 | `空格 q p`、`空格 q c` |
| Markdown 预览 | `:MarkdownPreviewToggle` |
| VimTeX PDF 预览 | `\lv` |

## 帮助与配置信息
